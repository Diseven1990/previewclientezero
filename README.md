# Cliente Zero · Amostra Clara

Site estático para GitHub Pages, pensado para mobile. Quatro decisões, cerca de 1–2 minutos. Sem registo, sem recolha de dados e sem dependências externas.

Copiar index.html, style.css, app.js e a pasta assets para o repositório. Em Settings → Pages, escolher Deploy from a branch e a pasta onde ficaram os ficheiros (por exemplo main / root).

O endereço final do GitHub Pages será usado no QR code da apresentação.

Clara e Linha Clara são um cenário fictício de demonstração. As respostas e o briefing pertencem apenas a esta amostra; não alteram a aplicação Cliente Zero original.
